Multi-empresa (tenants)

Uma única instalação do Teknisoft Contab serve várias empresas, com dados isolados entre si, e dentro de cada empresa trata a contabilidade de muitos clientes, cada um na sua base ERP.

Dois níveis de "empresa"

É importante distinguir os dois níveis com que a aplicação trabalha:

🏢

Tenant (o gabinete)

Quem usa a aplicação. Entra-se pelo NIF no ecrã de entrada. Cada tenant tem a sua base de dados, utilizadores, definições, logótipo, nome do assistente e ficheiros.

👥

Empresa cliente (entidade)

Cada cliente do gabinete. Vive dentro do tenant, tem ficha própria e está ligado a uma base de dados ERP no formato emp_XXX.

Isolamento de dados por tenant

  • Base de dados própria: cada NIF de tenant aponta para uma base MySQL distinta. Utilizadores, documentos, classificações, memória do assistente e definições nunca se misturam.
  • Ficheiros próprios: uploads, anexos e marca ficam em pastas separadas por tenant.
  • Identidade própria: nome da app, logótipo, ícone e até o nome e a personalidade do assistente IA podem ser diferentes em cada tenant.
  • Área do cliente própria: a extranet de cada tenant tem endereço próprio (t/{tenant}/cliente).
Mais-valia

O mesmo servidor pode alojar vários gabinetes (modelo SaaS) ou várias empresas de um grupo, sem instalações duplicadas e com atualizações aplicadas a todos de uma vez.

Várias bases ERP numa só operação

Dentro do tenant, o técnico vê numa só lista os documentos de todos os clientes que lhe estão atribuídos. Ao importar:

  1. O sistema identifica o adquirente de cada documento (pelo NIF lido do QR).
  2. Resolve a base ERP desse cliente (campo Base de dados ERP da ficha, por exemplo emp_227).
  3. Agrupa os documentos selecionados por base e importa cada grupo na base certa, numa única ação.
  4. Só pede ao utilizador para escolher a base quando há exatamente um cliente sem base definida.

Empresa base e autenticação no ERP

Todas as chamadas ao ERP-SINC são autenticadas com a Empresa base (Definições > Módulos > Contabilidade) e indicam, quando aplicável, a base de destino do cliente. Assim, um só token serve todos os clientes do gabinete.

Carteira de cada técnico

Os técnicos só veem e tratam as empresas cliente para as quais têm tarefas atribuídas (na ficha do cliente, separador Admin). Administradores veem todas. O mesmo princípio aplica-se às tarefas de fecho (IVA, SAF-T, Confirmação de Pasta).
